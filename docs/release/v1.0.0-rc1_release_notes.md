# 30 Days of Calm Execution — v1.0.0-rc1 Release Notes

Status: Release candidate  
Tag: `v1.0.0-rc1`  
Release type: V1 release-hardening baseline  
Product: 30 Days of Calm Execution

## Summary

`v1.0.0-rc1` is the first release candidate for **30 Days of Calm Execution**, a Kotlin-first Android app built with Jetpack Compose.

The app delivers a structured 30-day calm execution journey with daily practical tips, section-based progression, bookmark state, read-only completion status on Home, completion mutation from Detail / selected expanded Detail, detail reading screens, settings, accessibility support, and adaptive layout behavior for compact and expanded devices.

## Main user-facing changes

### Home

Home presents the full 30-day journey.

Tips are grouped into five sections:

- Start with Clarity;
- Build Focus;
- Protect Boundaries;
- Sustain Energy;
- Finish and Improve.

Tip cards show:

- image;
- day;
- category;
- title;
- preview;
- bookmark icon action;
- read-only completion status.

Bookmark is an icon action in the metadata row.

Completion is not mutated from Home. Home displays completion state only.

The Bookmarked chip gives bookmarking a visible product use case.

Empty bookmarked state is handled.

### Detail

Detail screen is the primary compact completion-mutation surface.

Detail screen shows:

- day;
- category;
- bookmark action;
- completion action;
- structured reading content.

Detail content is structured as:

- Problem;
- Tip;
- Why it helps;
- Try today.

Real tip images are visible.

Image descriptions are available for accessibility and are not shown as placeholder body text.

Bookmark state syncs with Home.

Completion changes made in Detail are reflected on Home as read-only completion status.

Opening Detail may mark a tip as viewed, but journey progress does not advance from viewed state alone. Journey progress is derived from completion/progression state.

### Settings

Settings opens from an icon button with the content description `Open settings`.

Detail back navigation uses an icon button with the content description `Navigate back`.

Settings supports:

- theme mode;
- dynamic color;
- reduced motion;
- reset progress.

Reset confirmation protects against accidental progress clearing.

### Expanded / tablet layout

Expanded layout shows feed on the left and detail on the right.

Selected tip is visually indicated in the feed.

Detail opens in the right pane after selection.

The selected expanded Detail pane supports bookmark and completion actions for the selected opened tip.

The Home/feed pane continues to show completion status as read-only.

The right pane includes a compact `← Journey feed` return control.

System Back and explicit return both clear selected detail and restore feed reachability.

### Branding

Final launcher icon assets were added for the release candidate.

Launcher icon change does not alter catalog content, frozen tip images, navigation, persistence, or product behavior.

## Known non-blocking issues / carryovers

The following are accepted for this release candidate and are not Blocker/Critical/High defects.

### D5-05-F09 — Compact landscape top app bar appears slightly low

Status: Investigated / Deferred.

Reason:

- no system-bar overlap;
- title and icons remain tappable;
- content starts below the app bar;
- no controls are hidden behind system UI;
- no crash or blank screen observed.

### Build / configuration warnings

Known warning carryovers:

- `android.newDsl=false` is deprecated and will be removed in AGP 10.0;
- deprecated Gradle features are used; Gradle 10 compatibility risk;
- `RawResourceCatalogDataSource.kt` Kotlin annotation default-target warning;
- native debug symbol strip warning for packaged AndroidX/DataStore libraries.

Disposition:

These are carried forward to post-release build modernization unless they become build failures.

### Dependency modernization watch items

Accepted for V1:

- Kotlin/KSP alignment should be revisited post-release;
- AndroidX Core/Lifecycle declared-version drift should be reviewed post-release;
- Gradle 10 / AGP 10 compatibility should be handled in a separate modernization task.
