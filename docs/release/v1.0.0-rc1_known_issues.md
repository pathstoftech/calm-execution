### KI-001 — Compact landscape top app bar appears slightly low

Severity: Low / Medium  
Area: UI / Window insets / Compact landscape  
Status: Investigated / Deferred  
Release impact: Accepted for `v1.0.0-rc1`

Observed behavior:

The compact landscape top app bar can appear slightly lower than expected near the system bar.

Acceptance result:

- app bar does not overlap system bars
- title and icons remain tappable
- content starts below the app bar

Accepted for V1. Revisit only if future device testing shows overlap, hidden controls, or unreachable navigation.

### KI-010 — Adaptive NavHost lifecycle / resizing watch item

Severity: Medium watch item  
Area: Architecture / Adaptive navigation  
Status: Deferred  
Release impact: Non-blocking

Observation:

A review noted that `CalmExecutionNavHost` is invoked through adaptive compact/expanded content paths. During layout-class transitions, there is a theoretical risk of NavHost disposal/recreation causing flicker or state reset.

Release evidence:

- Compact navigation tests passed.
- Expanded/adaptive tests passed.
- Regression suite passed.
- Manual orientation / resize sanity passed.
- No wrong destination, blank screen, crash, or lost bookmark/complete state was observed.

Decision:

Not classified as Critical or High for `v1.0.0-rc1` because the risk is not reproduced in release-hardening evidence. Track as a post-release architecture review item for foldables, resizing, and split-screen stress testing.

### KI-011 — ViewModel initial-state stutter watch item

Severity: Low / Medium watch item  
Area: UX / State restoration  
Status: Deferred  
Release impact: Non-blocking

Observation:

Some ViewModels use `stateIn` with `SharingStarted.WhileSubscribed(5_000)` and an initial empty state. A reviewer noted a theoretical risk of a brief loading/empty state flash when returning after the flow stops.

Release evidence:

- Regression suite passed.
- Manual exploratory pass did not report a blocking flash or broken state.
- Persistence and navigation state remained consistent.

Decision:

Accepted for `v1.0.0-rc1`. Revisit only if real users or extended device testing show visible stutter.

Severity: Low  
Area: Navigation / ViewModel arguments  
Status: Accepted  
Release impact: Non-blocking

Observation:
