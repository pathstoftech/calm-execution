## Accepted minor build/media notes

### Native debug-symbol strip warning

Status: accepted non-blocking build warning.

A clean local `assembleDebug --info` run reports that `libandroidx.graphics.path.so` and `libdatastore_shared_counter.so` cannot be stripped for some ABIs because the matching strip tool is unavailable. Gradle packages those libraries as-is and the build still completes successfully.

This is treated as a third-party native-library packaging warning, not an app behavior, correctness, or release-readiness blocker.

No Gradle workaround is applied in this release candidate because changing JNI packaging behavior only to silence a debug warning would be higher risk than accepting the warning.

### Screenshot metadata

Status: clean.

Repository screenshots under `docs/screenshots/` were checked for PNG metadata chunks. No `tEXt`, `iTXt`, `zTXt`, or `eXIf` metadata chunks were found.

A coarse full-binary string scan produced matches in some PNG files, but that scan searches compressed image data and is not treated as metadata evidence. No screenshot re-encoding or metadata stripping was applied.
